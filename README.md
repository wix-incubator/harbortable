# Harbor Table

A restaurant reservation concept showing tasting reservations, table inventory, service scheduling, and guest confirmation powered by Wix Headless.

This website is powered by Wix Headless and built using [wix-headless.dev](https://www.wix-headless.dev).

## Live Site

- [https://harbor-tab-6b04dc4c-gonenj.wix-site-host.com](https://harbor-tab-6b04dc4c-gonenj.wix-site-host.com)

## Source

- [https://github.com/wix-incubator/harbortable](https://github.com/wix-incubator/harbortable)

## What It Showcases

- Bookings experience built as a custom headless website
- Wix-managed backend capabilities surfaced through a custom Astro front end
- Public `llms.txt` and `robots.txt` configured through the Wix SEO txt APIs
- Deployment with `wix release`

## Local Development

```bash
yarn install
yarn dev
```

## Build

```bash
yarn build
```
